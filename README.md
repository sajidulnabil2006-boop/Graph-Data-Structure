# Graph Data Structure

A C programming project implementing a directed graph using an adjacency list.

## Features

* Create Graph
* Insert Edge
* Delete Edge
* Display Graph
* Search Edge
* Find In-degree and Out-degree
* Check Path
* DFS Traversal
* Count Vertices and Edges
* Find Maximum Degree

## Implementation

* **Language:** C
* **Data Structure:** Adjacency List
* **Graph Type:** Directed Graph
* **Traversal Algorithm:** Depth First Search (DFS)

## Files

* `GraphNew.c` — Graph implementation

## How to Run

Compile the C program using GCC:

```bash
gcc graph.c -o graph.exe
```

Then run:

```bash
./graph.exe
```

This project was developed as part of a C programming / Data Structures course project.
